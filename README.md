# vciso_page

Static site for security.jcady.org, published by GitHub Pages from `main`.

- `REVIEW-CHECKLIST.md`: what to check before a change is merged (every pull request starts with its short version).
- `docs/ARCHITECTURE.md`: diagrams of the pages and where each form sends data.
- `THEME.md`: the shared design system.
- `SECURITY.md`: reporting a vulnerability.
